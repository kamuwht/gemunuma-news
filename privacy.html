プライバシーポリシー

制定日：2026年10月8日

運営者kamuwht（以下「運営者」）は、「げむぬまニュース投稿システム」（以下「本アプリ」）で取り扱う情報について、次のとおり定めます。本アプリは運営者自身のYouTubeチャンネルを管理する個人用ツールであり、一般ユーザー向けのアカウント連携サービスは提供していません。

1. 取得・処理する情報

  • Google OAuth認証により発行されるアクセストークン、更新用トークンなどの認証情報。
  • YouTubeチャンネルのID、名称など、接続先を確認するための情報。
  • 投稿する動画ファイル、タイトル、概要欄、タグ、公開設定など、運営者が用意する投稿データ。
  • YouTubeから返される動画ID、動画の管理情報、公開設定、アップロード・変換処理の状態。
  • 重複投稿の防止や処理の確認に必要な動画ファイルの識別情報、投稿履歴、実行日時、処理記録。

2. 利用目的

これらの情報は、正しいチャンネルへの動画投稿、公開設定の確認、処理状況の照会、重複投稿の防止、不具合の調査、認証接続の維持のために使用します。広告配信、個人の行動分析、データ販売のためには使用しません。

3. 保存と保護

認証情報は、運営者が管理するサーバー上のn8nの認証情報管理機能を使用し、暗号化して保存します。投稿履歴・処理記録は同じ運営環境に保存し、一般公開しません。運営者はアクセス権限を管理し、認証情報を公開リポジトリや公開ページに掲載しません。

認証情報は接続の維持に必要な期間、投稿履歴は重複防止・運用確認に必要な期間保管します。運用終了時または削除が必要になった場合は、運営者が認証情報と不要になった保存記録を削除します。

4. 外部への送信・共有

動画の投稿・管理に必要なデータはGoogle／YouTubeのAPIへ送信します。動画やそのタイトル・概要欄などは、運営者が指定したYouTubeの公開範囲に従って表示されます。

Googleから取得した認証トークンやチャンネル管理情報を、台本生成・音声生成・編集に使用するAIサービスへ送信しません。Google APIから取得するユーザーデータを、AI・機械学習モデルの学習、改善、開発に利用しません。

取得したユーザーデータを販売したり、広告目的で提供したりしません。法令に基づく場合を除き、上記の機能を提供する目的以外で第三者へ開示しません。

5. Googleのデータ利用要件

本アプリによるGoogle APIから取得する情報の使用および他のアプリへの転送は、Limited Useの要件を含むGoogle API Services User Data Policyに従います。本アプリはYouTube APIサービスを使用しています。Google側の情報の取り扱いについてはGoogleのプライバシーポリシーをご確認ください。

6. 接続の解除と情報の削除

運営者はGoogleアカウントの接続管理画面から、本アプリへのアクセス権を取り消せます。

Google側でアクセス権を取り消しても、サーバー内の投稿履歴や保存済みの認証情報は自動削除されません。運営者がn8nの認証情報と必要な保存記録を削除します。既にYouTubeへ投稿された動画の削除・公開設定の変更は、YouTube Studioなどで別途行います。

7. このWebサイトについて

当サイトには独自のアクセス解析、広告、入力フォームを設置していません。ホスティングに使用するGitHub Pagesでは、GitHubがセキュリティなどの目的で訪問者のIPアドレスを記録します。詳しくはGitHubのプライバシーに関する説明をご確認ください。

8. お問い合わせと変更

本アプリに関するお問い合わせは、運営者のGitHubリポジトリで受け付けます。公開される場所のため、認証情報や個人情報を投稿しないでください。

運用内容に変更がある場合は、本ポリシーを更新して当サイトに掲載します。
